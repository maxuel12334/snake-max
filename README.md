# Snake Max

Snake Max é um jogo de cobrinha moderno criado por Maxuel.

## Arquivos principais

- `index.html`: página do jogo principal.
- `open.html`: página de acesso rápido para abrir o jogo no navegador.
- `style.css`: estilos visuais do jogo.
- `script.js`: toda a lógica do jogo.
- `manifest.json`: manifest do app para funcionar como PWA no Chrome.
- `icon.svg`: ícone do jogo.

## Como publicar no GitHub Pages

1. Instale o Git em seu computador: https://git-scm.com/downloads
2. Crie um repositório no GitHub.
3. No diretório do projeto, execute:

```powershell
cd C:\Users\Max\Documents\JogoCobrinha
git init
git add .
git commit -m "Publicar Snake Max no GitHub Pages"
git branch -M main
git remote add origin https://github.com/maxuel12334/snake-max.git
git push -u origin main
```

4. No GitHub, abra as configurações do repositório e ative o GitHub Pages para a branch `main`.
5. Aguarde alguns minutos e acesse o link do GitHub Pages.
